Colab demo

Open notebooks/colab_demo.ipynb in Google Colab to run a quick end-to-end demo (clone repo, download MIT-BIH subset, train for a few epochs, quantize model, and download artifacts).

Usage notes:
- If repository is private, provide a GitHub PAT when prompted in the notebook (use only in your Colab session). Don't share tokens.
- Use small --max-records and --epochs values for quick runs.
